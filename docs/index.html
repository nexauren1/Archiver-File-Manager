Mais controlo, menos atrito.

As ferramentas essenciais de gestão de ficheiros, com uma interface limpa e escolhas que respeitam a forma como trabalhas.

▤

Organização completa

Copia, move, renomeia, partilha, elimina e ordena os ficheiros, com seleção múltipla e favoritos.

▱

Arquivos sem complicação

Cria, explora e extrai arquivos ZIP e 7Z; acompanha o progresso das operações.

⌕

Android nativo

Desenvolvido para o teu dispositivo.

O Archiver é uma aplicação Android nativa em Kotlin, não uma página web dentro de uma aplicação.

  • Vistas detalhada, compacta e em grelha
  • Favoritos, ordenação e ficheiros ocultos opcionais
  • Acesso ao armazenamento controlado pelas permissões Android
Privacidade primeiro

Os teus ficheiros ficam no dispositivo.

A aplicação trabalha localmente e não exige uma conta. O acesso às pastas depende das permissões concedidas e das restrições do Android.

Ler a política de privacidade →
O Archiver é um projeto independente e não é afiliado a outras aplicações de gestão de arquivos. Antes de operações destrutivas, confirma os itens selecionados e mantém cópias de segurança dos ficheiros importantes.
