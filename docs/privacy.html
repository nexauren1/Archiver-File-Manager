Archiver

Política de privacidade

Última atualização: 18 de outubro de 2026.

Em resumo

O Archiver é um gestor de ficheiros Android em desenvolvimento. A aplicação trabalha com ficheiros no dispositivo e não pede uma conta. A permissão para gerir todos os ficheiros é usada para permitir navegação e operações no armazenamento partilhado.

Ficheiros e permissões

O utilizador escolhe os ficheiros e pastas com que a aplicação trabalha. Os ficheiros selecionados para copiar, mover, comprimir, extrair, editar ou eliminar são processados localmente pela aplicação. O Android pode continuar a restringir pastas privadas de outras aplicações, mesmo com acesso amplo.

Dados enviados

A versão atual não implementa contas, sincronização na cloud, análise de utilização ou publicidade. A aplicação não declara permissão de Internet no manifesto Android deste projeto. Esta declaração descreve o código do projeto no momento desta versão; confirma as permissões do APK que instalas.

Segurança

A aplicação fornece ferramentas para copiar, mover, comprimir e eliminar ficheiros. Antes de operações destrutivas, confirma os itens selecionados e testa com ficheiros sem importância. Nenhum software pode garantir ausência total de erros.

Contacto e alterações

Para comunicar dúvidas ou alterações de privacidade, usa o repositório do projeto.
